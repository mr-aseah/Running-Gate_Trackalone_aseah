# Running Gate / Trackalone

A browser-based RFID run timing and capture tool. Open `index.html` to use the application; no build step is required.

The active-session interface uses a high-volume two-column Live Gate with an optional Runner Overview and operational DONE acknowledgement queue. See [the PR #11 field-view guide](docs-pr11-live-gate.md).

New-session isolation, focus-independent RFID keyboard capture, and the browser-readiness banner are described in [the PR #12 capture reliability guide](docs-pr12-capture-reliability.md).
